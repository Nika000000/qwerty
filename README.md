# 🚎 Вебсайт «Житомир Рух»

> **Статус v0.1:** це демонстраційний прототип. Він не підключений до GPS/AVL або API перевізників; транспортні позиції, статуси, ETA та розклади в локальній моделі не є актуальними офіційними даними. Мапа OpenStreetMap потребує інтернет-з'єднання. Див. [паспорт проєкту](PROJECT_PASSPORT.md) і план v0.2.

**«Житомир Рух»** — це сучасний, функціональний та адаптивний вебсервіс для онлайн-моніторингу міського громадського транспорту, перегляду актуальних розкладів, інтерактивного планування поїздок та диспетчерського контролю у місті Житомир.

Проєкт реалізовано згідно з паспортом проєкту з акцентом на **максимальний інтерактивний функціонал** та **сучасний естетичний дизайн**.

## 🎨 Особливості нового дизайну

* **Сучасна колірна палітра:** глибокий індиго/темний сланець (`#0F172A`) у поєднанні з муніципальним електрик-блакитним (`#0284C7`), смарагдовим (`#10B981`) та попереджувальним бурштиновим (`#F59E0B`).
* **Адаптивність та глибина:** м'які тіні (`shadow-md`, `shadow-lg`), закруглені кути (`radius-xl`), плавні переходи при наведенні.
* **Покращений пошук:** плавна фільтрація маршрутів без втрати фокусу клавіатури, чіпи з великими номерами та кольорами ліній.
* **Інтерактивне табло зупинок:** відображення прогнозу прибуття (хвилини, статус запізнення, інклюзивність низької підлоги ♿).
* **Бортовий HUD водія:** великий цифровий спідометр, контрастні блоки зупинок, кольорова шкала запізнення/випередження.
* **Диспетчерський пункт:** зведені KPI-картки, таблиця активних рейсів із GPS-телеметрією та стрічка оперативних подій.
* **Живий годинник та індикатор GPS:** точний синхронізований час та статус зв'язку ТТУ в реальному часі.

## 🚀 Як відкрити та запустити проєкт

### Спосіб 1: Пряме відкриття у браузері (Без встановлення чогось додаткового)
Просто двічі клікніть будь-який із файлів у папці:
* [index.html](file:///c:/Users/Nika/Downloads/3predmet/index.html) — відкриє сторінку **Пасажира**
* [driver.html](file:///c:/Users/Nika/Downloads/3predmet/driver.html) — відкриє **Кабінет водія**
* [dispatcher.html](file:///c:/Users/Nika/Downloads/3predmet/dispatcher.html) — відкриє **Панель диспетчера**

Завдяки зібраному автономному бандлу [bundle.js](file:///c:/Users/Nika/Downloads/3predmet/js/bundle.js), сайт миттєво працює в усіх браузерах навіть без інтернет-сервера!

### Спосіб 2: Запуск локального сервера для Windows в один клік
Двічі клікніть:
```cmd
start.bat
```
Це відкриє сайт у браузері за адресою [http://localhost:8080](http://localhost:8080).

### Спосіб 3: Через термінал (Node.js)
```bash
node server.js
```
