# Житомир Рух — v0.2

Вебзастосунок для перегляду маршрутів і зупинок громадського транспорту Житомира. Це демонстраційний прототип із трьома окремими інтерфейсами: пасажир, водій і диспетчер.

## Запуск

Потрібен Node.js 18 або новіший. Залежності npm не використовуються.

1. Відкрийте термінал у папці проєкту.
2. Запустіть `node server.js`.
3. Налаштуйте службові паролі в змінних середовища й запустіть сервер (див. нижче).
4. Перейдіть на `http://localhost:8097`.
5. Щоб перебудувати клієнтський файл після зміни модулів, виконайте `node build.js`.

Альтернативно запустіть `start.bat` у Windows. Пасажирська сторінка відкрита для всіх. Службові сторінки потребують входу, а після входу відкривається тільки кабінет відповідної ролі.

### Паролі службових ролей

Задайте різні паролі для кожної ролі перед запуском сервера через environment-змінні або приватний локальний файл `.staff-secrets.json` (цей файл ігнорується Git та не доступний через HTTP). Якщо ні того, ні іншого немає, вхід для відповідної ролі вимкнений. Захист працює лише при запуску через цей `server.js`; не розгортайте файли як відкритий статичний сайт, бо статичний хостинг не виконує серверну перевірку доступу.

PowerShell:

```powershell
$env:DRIVER_PASSWORD = "довгий-окремий-пароль-водія"
$env:DISPATCHER_PASSWORD = "довгий-окремий-пароль-диспетчера"
node server.js
```

Не записуйте паролі у файли проєкту та не передавайте їх у Git. Сесія зберігається в HttpOnly cookie до 8 годин; список сесій зберігається в пам’яті процесу та очищується після перезапуску сервера. Для доступу через інтернет потрібен HTTPS і надійне зберігання секретів на сервері.

## Що вміє демо

- Показує карту міста Leaflet з підкладкою OpenStreetMap, маршрутними лініями, зупинками та демо-маркерами транспорту.
- Дає пасажиру шукати демо-схеми маршрутів і зупинок, будувати поїздку в локальній моделі та зберігати маршрути/зупинки.
- Показує тариф за способом оплати з посиланням на КП «Житомиртранспорт» і відкриває чинний графік для вибраного маршруту на zt.rozklad.in.ua.
- Планувальник знаходить прямі варіанти й пересадки за спільними зупинками у схемі маршрутів. Усі оцінки часу позначені як демонстраційні.
- Кабінет водія показує локальну модель зміни, маршруту й табеля після серверної перевірки пароля ролі.
- Диспетчерська показує демо-парк, фільтри, локальні повідомлення та CSV-експорт після серверної перевірки пароля ролі.

## Дані та обмеження

Реальні GPS/AVL і API перевізника не підключені. Карта, координати, локальні маршрути/зупинки, транспортні маркери, статуси, табло й оцінки часу є демонстраційними та не повинні використовуватися для планування реальної поїздки. Тарифи перевірені на сторінці КП «Житомиртранспорт» 04.11.2026. Чинні графіки відкриваються на zt.rozklad.in.ua; зовнішня сторінка може повідомляти про тимчасові зміни. Мапа потребує інтернету для завантаження тайлів OpenStreetMap; дані шрифтів можуть завантажуватися з Google Fonts.

Збережене та деякі налаштування працюють локально у `localStorage` цього браузера. Парольний вхід до ролей реалізований на сервері, але це спільні паролі з environment-параметрів, без індивідуальних облікових записів, відновлення пароля чи аудиту. Дані транспорту не є приватними: це демонстраційна модель без реальних диспетчерських API.
